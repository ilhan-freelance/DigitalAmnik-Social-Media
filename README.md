# Digital Amnik Website Frontend

A modern, high-performance React + Vite + Tailwind CSS web interface.

## Getting Started

### Prerequisites
- Node.js (v18+)

### Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start local development server:
   ```bash
   npm run dev
   ```
3. Open your browser at `http://localhost:3000`.

## Tech Stack
- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4
- **Animations:** Motion (Framer Motion) & Lenis Smooth Scroll
